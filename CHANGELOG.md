# Changelog

## 0.2.0

* Replaced KDE `KIdleTime` with the compositor-neutral
  `ext-idle-notify-v1` Wayland protocol.
* Added native Hyprland idle, resume, and idle-inhibitor handling.
* Added media playback retry handling after MPRIS blocks activation.
* Removed the KDE Frameworks build dependency.
* Added Waybar status, activation, settings, and deactivation controls.
* Added an optional Hyprland startup and keybinding fragment.
* Retained the Plasma widget as an optional integration.

## 0.1.0

* Initial KDE Plasma implementation.
